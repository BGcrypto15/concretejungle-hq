# Concrete Jungle

Demo website for Concrete Jungle Holdings LLC (hauling, cleanouts, scrap, labor). Static site, no build step.

- Brand settings and service list: top of `app.js`
- Quote form: set `formEndpoint` in `app.js` to the Formspree URL to turn on email delivery
- Bump `?v=` on `styles.css` and `app.js` in `index.html` after edits so phones load the new version

Built by Gomez Enterprise Group.
